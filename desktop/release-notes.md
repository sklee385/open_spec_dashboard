### 검증 범위

- 변경된 업무 검증 계획·결과 재사용, 정상 종료 뒤 상태 복구, 후보 범위 선택 및 변경 차단 회귀 검사
- 소유 Job/프로세스 식별과 변경된 검증 UI·릴리스 게시 검사
- backend/frontend 빌드와 실제 패키지 실행·종료·복구 smoke
- 실제 Electron ASAR 무설치 업데이트 교체·기존 앱 백업·새 버전 시작 확인

이번 배포에서는 전체 backend/frontend 및 desktop 테스트 suite를 실행하지 않았습니다. 변경 부분과 직접 영향 범위만 검사했습니다. 기존 전체 검사는 삭제하지 않았으며, 필요한 이유·장시간이 걸린다는 점·예상 소요 시간(모르면 미확인)을 안내하고 사용자가 명시 승인한 경우에만 `workflow_dispatch`의 `full_suite`로 선택 실행할 수 있습니다.
