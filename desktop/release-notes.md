### 질문·승인 화면 확대

- 긴 질문과 승인 내용을 크게 열어 볼 수 있습니다. 본문 스크롤과 결정 버튼을 분리하고 입력한 답변과 키보드 포커스를 유지합니다.

### 상태 점검과 안내 정리

- 명확히 정상인 보관 업무만 상태 점검 목록에서 숨깁니다. 실행·미확인·오류·복구 필요 업무는 계속 표시합니다.
- 추가 지시 안내를 접고 다시 볼 수 있습니다. 같은 내용 조회에는 접힌 상태를 유지하며 요청·문서 버전·상태·오류가 바뀌면 다시 표시합니다. 요청과 초안은 유지합니다.

### 데스크톱 초안 저장 수정

- 업무공간 준비·통합·후보 편집의 초안과 전송 전 요청 영수증을 데스크톱 프로필에 저장하도록 허용 키 불일치를 수정했습니다. 미해결 요청의 자동 중복 전송 차단과 저장 실패 시 보존 동작은 유지합니다.

### 검증 범위

최종 통합 코드의 직접 영향 검사와 프런트엔드·백엔드 빌드를 확인합니다. 격리 Electron 창의 실제 preload→IPC→DraftStore 저장 연결, 제품 전용 Chromium의 질문 확대·안내 접기 합성 화면 및 상태 점검 시나리오를 확인합니다. 합성 화면 검증은 실제 운영 업무 전체 경로 검증과 구분합니다. 배포 CI는 직접 영향 검사, 필수 게시 검증, 패키지 정상 기동·종료 및 실제 ASAR portable 업데이트 smoke를 수행합니다.

전체 backend/frontend 및 desktop 테스트 suite를 실행하지 않았습니다. 실제 모델 실행이나 모든 환경의 동작까지 검증한 것은 아닙니다.
