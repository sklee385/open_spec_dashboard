### 프로젝트 선택 상자 유지

- 활동 상태나 프로젝트 목록이 갱신될 때 열어 둔 프로젝트 선택 상자가 선택하지 않았는데 닫히는 문제를 수정했습니다.
- 선택 상자의 컴포넌트와 포커스를 유지하며 주기 조회와 안전 잠금은 유지합니다.
- 합성 화면에서 설정 초안 보존 및 다른 업무의 늦은 응답 차단도 확인했습니다. 앱 전체 성능이 개선됐다고 단정하는 변경은 아닙니다.

### 검증 범위

Codex 내장 브라우저에서 수정 전 자동 닫힘·DOM 교체를 재현했고, 수정 후 활동 8회·소스 3회 갱신에도 목록과 포커스 유지·선택 상자 교체 0회를 확인했습니다. 직접 영향 5개 파일 10개 검사와 프런트엔드 빌드가 통과했습니다. 배포 CI는 해당 직접 영향 검사와 기존 필수 게시·패키지·업데이트 smoke를 수행합니다.

이번 배포에서는 전체 backend/frontend 및 desktop 테스트 suite를 실행하지 않았습니다. 이전 수동 관리 기능의 무관한 단위 suite는 자동 반복하지 않으며 기존 패키지 일일 현황판 smoke는 유지합니다.
