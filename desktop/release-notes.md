### 화면 응답과 수동 관리 상태

- 문서 열기·조회 중 화면 이동과 조회 취소를 지원합니다. 변경 처리 후 상태 확인은 별도로 표시하고 중복 변경은 차단합니다.
- 업무 전체 또는 현재 실행 회차의 관리 상태를 수동 변경할 수 있습니다. 사유·변경 전후·시각·회차를 기록하고 동시 충돌과 중복 제출을 검사합니다.
- 관리상 완료·보관은 보드의 관리 표시입니다. 실제 실행·종료 잠금·검증된 완료·OpenSpec 파일 보관은 별도로 유지됩니다. 자동 표시로 되돌릴 수 있습니다.
- 사용 위치: 업무 화면 → 수동 관리 상태. 관리상 보관 항목은 보관된 변경 표시를 켜서 찾을 수 있습니다.

### 검증 범위

합성 데이터로 응답 지연·조회 취소·보드 복귀와 관리상 완료→보관·감사 이력을 Codex 내장 브라우저에서 확인했습니다. 변경·직접 영향 검사와 제품 빌드 및 기존 격리 패키지 검증을 수행하며 전체 테스트 suite는 실행하지 않습니다.

이번 배포에서는 전체 backend/frontend 및 desktop 테스트 suite를 실행하지 않았습니다. 기존 패키지 일일 현황판 smoke는 유지하며, 단위 검사는 이번 변경과 직접 영향 범위만 선택합니다.
