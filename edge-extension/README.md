# OpenSpecBoard Edge 연결 확장

사용자가 선택한 HTTP/HTTPS 탭 하나를 OpenSpecBoard 업무에 연결하는 Manifest V3 확장입니다. 자동 설치·스토어 게시·Edge 원격 디버깅은 사용하지 않습니다.

## 수동 설치와 연결

1. Edge에서 `edge://extensions`를 열고 개발자 모드를 켭니다.
2. **압축 풀린 확장 로드**를 선택하고 이 `edge-extension` 폴더를 지정합니다. 폴더는 설치 후에도 유지하세요.
3. OpenSpecBoard의 지원되는 새 업무에서 Edge 연결 코드를 발급받습니다.
4. 연결할 일반 웹 탭을 선택하고 확장 버튼을 누릅니다.
5. 업무 화면의 `http://127.0.0.1:<포트>` 주소와 일회용 코드를 입력한 뒤 **현재 탭 연결**을 누릅니다. 코드는 120초 뒤 만료됩니다.
6. 확장과 업무 화면에서 연결 상태·대상 탭을 확인합니다. 해제할 때는 확장의 **연결 해제** 또는 업무 화면의 해제 기능을 사용합니다.

코드가 만료됐거나 서버가 재시작됐다면 새 코드를 발급하세요. 기존 연결이 표시되면 먼저 해제합니다. 브라우저를 완전히 종료한 뒤에는 다시 연결해야 합니다. 확장 소스 업데이트 후에는 확장 관리 화면에서 다시 로드하고 다시 연결합니다.

## 동작 범위와 권한

- `activeTab`과 `scripting`: 확장 버튼으로 사용자가 선택한 탭의 메인 문서만 읽고 조작합니다. 사이트 전체의 상시 접근 권한은 요청하지 않습니다.
- `storage`: 연결 토큰을 확장 전용 세션 저장소에 보관합니다. 페이지 스크립트나 관찰 결과에는 토큰을 전달하지 않습니다.
- `alarms`: 서비스 워커가 중단됐을 때 연결 폴링을 재개합니다.
- 호스트 권한은 `http://127.0.0.1/*` 로컬 연결 서비스만 포함합니다. 임의 주소로 연결하거나 이동하는 명령은 지원하지 않습니다.
- 연결은 처음 선택한 탭 ID와 사이트 origin에 고정됩니다. 탭을 닫거나 다른 사이트로 이동하면 해제합니다. 같은 사이트에서 문서가 바뀌면 새 관찰이 필요합니다.
- `observe`, `click`, `fill`, `scroll`, `capture`만 지원합니다. 입력은 일반 input/textarea만 지원하며 비밀번호·파일·읽기 전용 입력은 거절합니다. iframe·shadow DOM 내부는 지원하지 않습니다.
- 클릭·입력·스크롤은 새 관찰 ID를 사용해야 하며, 실행 후 그 관찰은 폐기됩니다. 스크롤은 1~2000px입니다. DOM 변화도 기존 관찰을 무효화합니다.
- 캡처는 연결한 탭이 활성 상태이고 창이 포커스를 가질 때만 가능합니다. PNG가 3MiB를 초과하면 실패합니다. 탭을 자동 선택하지 않습니다.
- 워커 복구 시 기존 관찰을 폐기하고, 실행 여부가 불확실한 명령은 실패로 보고합니다. 입력을 자동 재실행하지 않습니다.
- 연결 교체·해제 시 관찰 소유권을 바꾸고, 비동기 처리 중 이전 연결의 명령이 새 업무로 넘어가지 않도록 검사합니다. 명령의 `expiresAt`(Unix 밀리초)을 실제 DOM 실행 직전에도 확인합니다.
- DOM 실행과 캡처 직전에는 인증된 `GET /commands/<명령 ID>`로 서버의 현재 실행 권한을 다시 확인합니다. 이미 브라우저가 실행하기 시작한 입력은 해제로 되돌릴 수 없으므로 실행 결과를 새 관찰로 확인하세요.

## 자동 검증

프로젝트 루트에서 실행합니다. 기존 개발 의존성인 jsdom과 Node 내장 테스트 러너를 사용합니다.

```powershell
./scripts/node.ps1 --test edge-extension/test/*.test.cjs
```

모의 Chrome API/HTTP 전송과 합성 DOM 검증입니다. 실제 Edge 설치·연결 성공을 의미하지 않습니다.

## 사용자 수동 확인

실제 Edge 검증은 사용자가 수행합니다.

1. 테스트할 웹페이지를 명시적으로 연결한 뒤 제목·URL·본문·버튼·일반 입력란을 관찰합니다.
2. 새 관찰로 버튼 클릭·일반 입력·스크롤을 확인하고 이전 관찰 재사용이 실패하는지 확인합니다.
3. 비밀번호와 파일 입력이 조작 대상에서 제외되는지 확인합니다.
4. 연결 탭의 활성·포커스 상태에서 캡처하고, 다른 탭을 선택한 상태에서는 캡처가 거절되는지 확인합니다.
5. 같은 사이트 이동 후 새 관찰이 필요한지, 다른 사이트 이동·탭 닫힘·해제 후 실행이 거절되는지 확인합니다.
6. 확장 다시 로드 후 입력이 중복 실행되지 않고 재연결이 필요한지 확인합니다.

세션 서버(13003)는 질문·승인·업무 실행이 모두 멈춘 뒤 프로젝트 지침에 따라 명시적으로 반영합니다. 확장이 서버를 재시작하지 않습니다.
