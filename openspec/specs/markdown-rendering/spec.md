# markdown-rendering Specification
## Purpose

업무 문서의 구조를 유지하여 사용자가 작성한 문서와 AI가 생성한 문서를 동일한 기준으로 읽도록 한다. 표와 다이어그램을 실제 콘텐츠로 표시하고 큰 콘텐츠와 잘못된 문법도 작업 화면에서 확인할 수 있도록 한다.

## Requirements
### Requirement: 문서 화면의 동일 렌더링
시스템은 업무 문서 미리보기·변경 상세·명세 조회에서 동일한 Markdown 표시 기준을 적용해야 한다(SHALL). 작성 주체에 관계없이 제목, 목록, 인용, 코드, 링크, 이미지와 구분선을 표시하고 저장 원본을 변경해서는 안 된다(MUST).

#### Scenario: 같은 문서를 여러 화면에서 열람
- **WHEN** 사용자가 동일한 Markdown을 각 문서 화면에서 연다
- **THEN** 같은 요소가 같은 규칙으로 표시되며 파일 원문은 그대로 유지된다

### Requirement: 표와 체크리스트
시스템은 GFM 표의 머리글·행·열·정렬과 체크리스트의 체크 여부를 표시해야 한다(SHALL). 미리보기의 체크리스트를 조작하여 저장 문서가 변경되어서는 안 된다(MUST).

#### Scenario: 정렬이 있는 표와 체크리스트
- **WHEN** 문서에 정렬 기호가 있는 표와 완료·미완료 목록이 포함된다
- **THEN** 표 구조·정렬과 각 체크 상태가 보존되어 표시된다

### Requirement: Mermaid 다이어그램
시스템은 mermaid 언어로 표시된 코드 블록을 다이어그램으로 렌더링해야 한다(SHALL). 다른 언어 블록은 코드로 유지하고, 잘못된 Mermaid 문법과 크기 제한 초과는 오류 안내 및 원문 열람으로 처리해야 한다(SHALL).

#### Scenario: 유효한 다이어그램
- **WHEN** 유효한 Mermaid 흐름도 또는 시퀀스 다이어그램이 포함된다
- **THEN** 시스템은 해당 블록을 실제 도식으로 표시한다

#### Scenario: 실패한 블록과 정상 문서의 공존
- **WHEN** Mermaid 블록 하나를 렌더링할 수 없다
- **THEN** 해당 블록에 오류와 원문을 표시하고 나머지 문서는 계속 표시한다

### Requirement: 큰 콘텐츠 열람
시스템은 넓은 표와 코드 블록에 가로 스크롤을 제공하고, 다이어그램에 가로·세로 스크롤 및 확대·축소·초기화 동작을 제공해야 한다(SHALL). 콘텐츠가 문서 영역 밖의 전체 화면 폭을 밀어내서는 안 된다(MUST).

#### Scenario: 좁은 화면에서 큰 다이어그램 열람
- **WHEN** 다이어그램의 원래 크기가 문서 영역보다 크다
- **THEN** 사용자는 스크롤과 확대·축소로 전체 내용을 확인하고 초기 배율로 되돌릴 수 있다

### Requirement: 안전한 문서 콘텐츠
시스템은 원문 HTML 및 다이어그램에 포함된 스크립트·이벤트 실행을 허용해서는 안 된다(MUST). 위험한 링크 프로토콜과 이미지 주소는 차단하고, 외부 링크를 새 창으로 여는 경우 원래 창에 대한 접근을 차단해야 한다(SHALL).

#### Scenario: 실행 코드를 포함한 문서
- **WHEN** 문서가 스크립트나 위험한 주소의 링크·이미지를 포함한다
- **THEN** 해당 코드와 주소가 실행되지 않으며 나머지 문서는 계속 표시된다

### Requirement: 접근성과 리소스 실패 처리
시스템은 이미지 대체 텍스트와 의미 있는 표 머리글을 유지하고 다이어그램에 원문 열람 동작을 제공해야 한다(SHALL). 이미지 또는 렌더러 로딩 실패는 해당 콘텐츠 영역에서 안내해야 한다(SHALL).

#### Scenario: 외부 이미지 로딩 실패
- **WHEN** 허용된 이미지 주소에 접근하지 못한다
- **THEN** 문서 나머지 부분을 유지하면서 대체 텍스트와 로딩 실패를 표시한다
