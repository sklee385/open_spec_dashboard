# artifact-editing Specification

## Purpose

사용자가 AI가 작성한 OpenSpec 문서를 업무 화면에서 읽고 직접 수정하거나 AI에 수정 요청할 수 있도록 하고, 동시에 발생하는 변경으로 편집 내용이 유실되는 일을 방지한다.

## Requirements

### Requirement: 문서 조회와 직접 저장
시스템은 연결된 변경의 제안서·설계·명세·작업 목록을 편집 및 미리보기로 제공하고, 저장한 내용을 실제 OpenSpec 파일에 반영해야 한다(SHALL).

#### Scenario: 생성된 명세 직접 수정
- **WHEN** 사용자가 명세 내용을 수정하고 저장한다
- **THEN** 실제 파일과 화면에 저장 결과가 반영되고 같은 업무에서 이어서 사용할 수 있다

### Requirement: 저장되지 않은 편집 보호
시스템은 저장 여부를 표시하고 문서 이동 또는 화면 종료로 미저장 내용이 사라질 때 사용자에게 저장·폐기·이동 취소 선택을 제공해야 한다(SHALL).

#### Scenario: 편집 중 다른 문서 선택
- **WHEN** 미저장 내용이 있는 상태에서 사용자가 다른 문서를 선택한다
- **THEN** 시스템은 현재 편집을 보호하는 선택을 제공하며 사용자 선택 전 편집을 폐기하지 않는다

### Requirement: 변경 충돌 감지
시스템은 읽은 이후 다른 주체가 변경한 문서에 대한 저장을 충돌로 처리해야 한다(MUST). 기존 파일과 사용자 초안을 보존하고 최신 내용 비교와 명시적 재적용을 제공해야 한다(SHALL).

#### Scenario: AI 수정과 수동 저장의 충돌
- **WHEN** 사용자가 편집하는 동안 AI가 같은 파일을 수정한 뒤 사용자가 기존 버전으로 저장한다
- **THEN** 시스템은 저장을 거부하고 최신 파일과 사용자 초안을 비교할 수 있게 한다

### Requirement: 같은 세션의 AI 문서 수정
시스템은 문서 수정 요청을 현재 업무의 Codex 대화에 전달하고 실제 변경 파일과 차이를 표시해야 한다(SHALL). 요청 시 저장된 문서의 최신 내용을 사용해야 한다(MUST).

#### Scenario: 직접 저장 후 AI 수정 요청
- **WHEN** 사용자가 문서를 직접 저장한 다음 AI에 추가 수정을 요청한다
- **THEN** 같은 대화에서 최신 문서를 바탕으로 수정하고 변경 결과를 화면에 표시한다

### Requirement: 문답 기반 문서 작성과 반복 검토
시스템은 문서 작성과 수정 과정에서 사용자 의견, AI 확인 질문, 사용자 답변, 문서 반영과 결과 검토를 같은 업무에서 반복할 수 있게 해야 한다(SHALL). 문서가 생성되거나 수정되었다는 이유만으로 검토를 완료 처리해서는 안 된다(MUST).

#### Scenario: 초안 검토 후 여러 차례 수정
- **WHEN** 사용자가 AI 초안을 보고 수정 요청과 확인 질문의 답변을 반복한다
- **THEN** 시스템은 현재 문서와 대화의 연결을 유지하며 각 수정 결과를 표시하고 추가 문답을 계속 받는다

#### Scenario: 문답을 마치고 구현 단계 선택
- **WHEN** 사용자가 최신 문서를 확인하여 검토 완료 후 구현 시작을 선택한다
- **THEN** 시스템은 검토한 문서 버전을 기록하고 같은 Codex 대화에서 구현을 진행한다

### Requirement: 문서 경로 제한
시스템은 문서 쓰기 요청을 해당 업무에 연결된 OpenSpec 문서로 제한하고 상대 경로 이탈과 심볼릭 링크를 통한 경계 이탈을 거부해야 한다(MUST).

#### Scenario: 프로젝트 밖 문서 수정 시도
- **WHEN** 문서 저장 요청이 허용 경계 밖으로 해석되는 경로를 지정한다
- **THEN** 시스템은 파일을 수정하지 않고 접근 오류를 반환한다

### Requirement: 계획 변경의 재검토
시스템은 구현 시작 이후 계획 문서가 수정되면 재검토 필요 상태를 표시하고 변경된 계획을 확인하기 전 새 구현 실행과 최종 완료를 차단해야 한다(SHALL).

#### Scenario: 구현 도중 명세 수정
- **WHEN** 구현 시작 후 사용자가 명세를 저장한다
- **THEN** 시스템은 변경된 문서와 재검토 필요 상태를 표시하고 후속 실행 전에 검토를 요구한다
