# app-version-display Specification

## Purpose
웹과 데스크톱 사용자가 업무 화면을 벗어나지 않고 현재 사용하는 앱의 버전을 확인하도록 한다. 문의와 업데이트 결과 확인 시 같은 제품 버전 기준으로 대화할 수 있게 한다.

## Requirements

### Requirement: 공통 상단의 현재 버전 표시

시스템은 웹·데스크톱 공통 상단 로고 옆에 현재 앱 버전을 항상 텍스트로 표시해야 한다(SHALL). 메뉴나 설정을 열지 않고 확인할 수 있어야 한다.

#### Scenario: 웹 화면 열기
- **WHEN** 사용자가 웹 앱을 연다
- **THEN** 공통 상단에서 현재 앱 버전을 확인할 수 있다

#### Scenario: 데스크톱 화면 열기
- **WHEN** 사용자가 데스크톱 앱을 연다
- **THEN** 공통 상단에서 현재 앱 버전을 확인할 수 있다

### Requirement: 탐색 및 좁은 화면에서 표시 유지

시스템은 공통 상단을 사용하는 화면을 전환하거나 화면 폭이 좁아져도 버전 텍스트를 유지해야 한다(SHALL). 버전이 기존 상단 조작 요소를 가리면 안 된다.

#### Scenario: 화면 전환
- **WHEN** 사용자가 칸반·명세·프로젝트 화면 사이를 이동한다
- **THEN** 공통 상단에 같은 버전이 유지된다

#### Scenario: 좁은 화면
- **WHEN** 사용자가 375px 너비에서 앱을 연다
- **THEN** 메뉴를 열지 않고 버전을 읽을 수 있으며 기존 상단 조작 요소를 사용할 수 있다

### Requirement: 제품 버전의 일관된 표기

- 제품 버전 출처와 표기 방식은 사용자 답변 ‘제안대로 결정’에 따라 확정했다. 루트 제품 버전을 빌드 시 주입하며 `v<제품 버전>` 형식으로 표시한다.

시스템은 현재 제공되는 앱 빌드의 제품 버전을 `v<제품 버전>` 형식으로 표시해야 한다(SHALL). 데스크톱 배포물의 표시는 패키징된 앱 버전과 일치해야 한다. 프런트엔드 하위 패키지 버전이나 다운로드 가능한 최신 버전을 현재 버전으로 표시하면 안 된다.

#### Scenario: 제품 버전과 하위 패키지 버전이 다름
- **WHEN** 제품 버전이 `0.1.2`이고 프런트엔드 패키지 버전이 `0.1.0`인 빌드를 실행한다
- **THEN** 상단은 `v0.1.2`를 표시한다

#### Scenario: 새 버전 다운로드 후 재시작 전
- **WHEN** 데스크톱에서 새 버전을 다운로드했으나 현재 앱을 재시작하지 않았다
- **THEN** 상단은 현재 실행 중인 앱의 버전을 유지한다

### Requirement: 버전 정보 누락 시 대체 표시

- 대체 문구 `버전 확인 불가`는 사용자 답변 ‘제안대로 결정’에 따라 확정했다.

시스템은 현재 버전 정보가 없거나 비어 있으면 `버전 확인 불가`를 해당 화면 언어에 맞게 표시해야 한다(SHALL). 버전 표시 실패로 다른 업무 기능이 중단되면 안 된다.

#### Scenario: 버전 정보 누락
- **WHEN** 버전 정보를 사용할 수 없다
- **THEN** 상단에 대체 문구가 표시되고 업무 화면은 계속 사용할 수 있다
