# AI 개발 도구 선택

- 등록일: 2026-10-24
- 상태: 후속 아이디어
- 현재 목표 포함 여부: 제외

## 배경

현재 프로젝트의 목표는 OpenSpec 작업 화면 안에서 아이디어 구체화, AI 질의응답, 문서 편집, 개발 실행, 검증과 완료 처리를 이어서 수행하는 것이다. 현재 목표에서는 AI 개발 도구로 Codex를 사용한다.

## 아이디어

기본 AI 개발 도구는 Codex로 유지하면서, 사용자가 다른 AI 개발 도구를 선택할 수 있는 기능을 후속 목표로 제공한다.

## 추후 결정할 사항

- 지원할 AI 개발 도구와 연결 방식
- 도구 선택을 적용할 범위: 전체 설정, 프로젝트 또는 개별 작업
- 도구 변경 시 기존 대화와 작업 맥락을 이어가는 방식

## 범위 구분

현재 목표의 구현 요건에 AI 개발 도구 선택 기능을 포함하지 않는다. 이 문서는 아이디어 기록이며 구현을 시작한 변경이나 확정된 설계가 아니다.
