# Markdown 뷰어 고도화: 다이어그램·테이블 등 문서 요소 완전 지원

사용자가 작성하거나 AI가 생성하는 문서는 Markdown(.md) 파일로 관리하지만, 현재 뷰어는 문서의 표현을 충분히 지원하지 못해 내용을 확인하기 불편하다. 작업 화면에서 문서를 온전히 읽을 수 있도록 Markdown 뷰어를 고도화한다.

다이어그램은 코드 블록 그대로 노출하지 않고 실제 도식으로 렌더링하며, 테이블은 행·열·정렬이 유지된 표로 표시한다. 제목, 목록, 체크리스트, 코드 블록, 링크, 이미지 등 문서에 사용되는 Markdown 요소도 정상적으로 표시해야 한다. 사용자 작성 문서와 AI 생성 문서에 같은 렌더링 기준을 적용한다.

넓은 표와 큰 다이어그램도 내용이 잘리거나 레이아웃이 깨지지 않게 확인할 수 있어야 한다. 지원할 다이어그램 문법(예: Mermaid), Markdown 확장 범위, 확대·축소 등 상세 열람 기능은 추후 설계에서 확정한다.

이 문서는 신규 아이디어 기록이며, 구현 범위와 우선순위는 추후 결정한다.
