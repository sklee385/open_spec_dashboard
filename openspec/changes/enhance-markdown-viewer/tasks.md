# Tasks

구현은 사용자가 계획 문서를 검토한 뒤 명시적으로 요청할 때 시작한다. 아래 체크박스는 구현 진행률이며 문서 작성으로 완료 처리하지 않는다.

## 1. 공통 Markdown 렌더러

- [ ] 1.1 remark-gfm을 포함한 공통 MarkdownDocument를 도입하고 제목·목록·인용·코드·취소선·표 정렬·읽기 전용 체크리스트·링크를 프런트엔드 테스트로 검증한다.
- [ ] 1.2 허용 URL 정책과 이미지 실패 표시·referrer 제한을 적용하고 위험 프로토콜·원문 HTML·외부 링크 속성·대체 텍스트 사례를 테스트한다.
- [ ] 1.3 지원 문법과 미지원 원문 처리, 상대 이미지 주소의 제한을 사용자 문서에 기록하고 예제 문서와 렌더러 테스트의 대응을 확인한다.

## 2. 다이어그램과 큰 콘텐츠

- [ ] 2.1 Mermaid 지연 로드·고유 ID·SVG 정제·strict 설정을 구현하고 흐름도·시퀀스·악성 입력·64KiB 초과·문법 실패·로드 실패를 테스트한다.
- [ ] 2.2 렌더링 세대 보호와 블록별 실패 경계를 구현하고 초안 연속 수정 시 오래된 도식이 덮어쓰지 않으며 다른 문서는 유지되는지 테스트한다.
- [ ] 2.3 표·코드의 가로 스크롤과 도식의 양방향 스크롤·25~200% 확대·초기화·원문 열람을 구현하고 버튼 접근성 및 배율 상태를 테스트한다.

## 3. 화면 연결과 통합 검증

- [ ] 3.1 WorkRoom·DetailModal·SpecsView의 문서 표시를 공통 렌더러로 전환하고 동일 원문의 화면별 결과와 저장 원본 불변을 회귀 테스트로 검증한다.
- [ ] 3.2 npm test와 npm run build를 실행하고 Microsoft Edge의 ChatGPT 확장에서 다크 모드·좁은 화면·큰 표·도식 확대를 확인한다. 확장에 접근할 수 없으면 미검증으로 기록한다.
