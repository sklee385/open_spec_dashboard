# [현재 목표] Codex 개발 실행부터 검증·완료까지 UI에서 처리

문서 확인 이후에도 외부 AI 도구로 이동하지 않고, UI에서 Codex에 구현을 요청하고 진행 상황과 결과를 확인할 수 있게 한다. 같은 작업 안에서 추가 지시와 수정 요청, 변경 코드·검증 결과 확인, 완료 처리를 이어간다. 실행 연결 방식과 완료 판정 기준은 추후 설계에서 확정한다. AI 도구 선택 기능은 후속 목표로 분리한다.
