# [현재 목표] AI 작성 문서 직접 편집 및 수정 요청

UI에서 AI가 작성한 OpenSpec 제안서·설계·명세·작업 목록을 확인하고 사용자가 직접 수정할 수 있게 한다. 문서 수정을 위해 외부 편집기로 이동하는 불편을 해소한다. AI에게 문서 수정을 요청하는 흐름도 같은 작업 화면에서 이어지도록 설계한다. 상세 편집 방식과 변경 반영 규칙은 추후 설계에서 확정한다.
