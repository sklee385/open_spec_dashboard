# 변경 완료된 파일 목록과 수정 내용 조회

## 목적

완료된 작업에서 어떤 파일이 바뀌었는지 확인한다.

파일별로 무엇을 수정했는지 쉽게 검토한다.

## 주요 기능

- 작업별로 변경된 파일 목록을 보여준다.

- 파일의 추가·수정·삭제 상태를 구분한다.

- 파일을 선택하면 변경 전후 차이를 보여준다.

- 어떤 작업에서 발생한 변경인지 표시한다.

## 추후 결정할 사항

- 변경 전후를 비교하는 기준

- 파일 목록과 수정 내용을 표시할 위치

- Git이 없는 프로젝트의 변경 확인 방식

## 기존 요구사항과의 관계

`unified-codex-work-session`의 코드 차이 조회 요구사항과 중복될 수 있다.

구체화할 때 기존 구현 범위를 먼저 확인한다.

## 등록 상태

아이디어만 등록했다.

구현 범위와 우선순위는 아직 확정하지 않았다.

## 사용자 원문

변경 완료 된 파일 목록과 수정 내용을 볼수 있게 해줘
