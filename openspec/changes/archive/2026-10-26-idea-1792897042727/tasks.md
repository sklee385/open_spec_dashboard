# Tasks

기존 완료 표시는 이전 범위에서 그대로 유지되는 항목의 이력이다. 사용자의 최신 문서 검토 완료 및 명시적 구현 시작 지시에 따라 네이티브 전달을 구현했다. 아래 체크는 작업별 구현·검증 기록이며 사용자 결과 검토나 업무 완료를 대신하지 않는다. 새 검증 근거는 `verification.md`의 네이티브 범위 기록을 따른다.

## Workflow follow-up

- 최종 문서 검토와 구현 전환은 `proposal.md`에 기록한 사용자 확인 원칙을 따른다. 사용자가 최신 문서 검토 완료와 구현 시작을 명시하여 현재는 implementation 단계다. 작업 체크로 사용자 결과 검토·업무 완료를 자동 처리하지 않으며 항목별 승인 상태는 추가하지 않는다.
- 세션 서버 변경 반영은 모든 업무 실행·답변·승인 대기가 해소된 후 명시적으로 수행한다. 일반 웹 서버 재시작과 함께 자동 종료하지 않는다.
- 구현·검증 후 사용자 결과 검토를 받고, 별도 지시가 있으면 변경 보관을 진행한다.
