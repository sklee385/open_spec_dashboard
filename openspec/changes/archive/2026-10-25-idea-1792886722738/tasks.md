- 이번 요청은 문서 수정만 허용한다. 제품 코드는 수정하지 않고, 추가 구현 전에 사용자에게 최신 문서 재검토를 다시 받는다. 문서 검토 완료와 브라우저 검증 결과 확인, 구현 결과의 최종 검토는 별개다.
- 검증 담당·방법만 변경하며 다국어 기능의 명세·설계상 동작은 유지한다. 아래 구현 재개·승인 시도 내용은 과거 기록이다.

사용자 직접 검증 기준:
