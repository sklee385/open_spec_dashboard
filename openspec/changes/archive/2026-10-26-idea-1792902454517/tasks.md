2026-10-26 사용자는 직접 게시 방식을 선택한 뒤 “이제 진행 해”라고 지시하여 최초 v0.1.1 직접 게시 작업을 수행했다. 이후 무설치 배포와 무설치 상태를 유지하는 자동 업데이트 개발을 명시적으로 요청해 7번 범위를 추가 구현·검증한다. 기존 구현·검증 근거와 완료 체크는 보존한다. 체크하지 않은 항목은 일부 코드가 있어도 해당 항목의 전체 검증까지 완료하지 않은 상태다. 사용자 결과 검토와 완료 확인은 별도로 필요하다. 근거는 [verification.md](verification.md)에 기록한다.

`release/windows-v0.1.1` 브랜치·`v0.1.1` 태그와 [정식 릴리스](https://github.com/sklee385/open_spec_dashboard/releases/tag/v0.1.1)를 게시했다. 5.4의 직접 게시·공개 다운로드 검증을 완료했고, Actions 실행은 확인하지 못해 5.1은 미완료다. 게시 완료를 실제 두 버전 간 설치·데이터 보존이나 업무 최종 완료로 확대하지 않는다.

- 제안서·설계·두 명세·작업 목록을 사용자에게 검토받고, 수정 의견을 같은 변경에 반영한다. 사용자 문서 검토 후 별도의 구현 시작 지시가 있어야 아래 작업을 시작한다.
- 데스크톱 구성은 사용자 수정 제안서의 Electron 권장안을 기준으로 한다. 배포 대상은 Windows x64, 배포 저장소는 `sklee385/open_spec_dashboard`다.
- 사용자 최신 지시에 따라 macOS 지원·배포·검증과 Edge 화면 검증은 범위에서 제외한다. Windows 앱 자체의 화면·설치·트레이·업데이트 검증은 유지한다.
- 저장소는 공개되어 있다. 2026-10-26 사용자가 인증서 없는 개인용 GitHub 업데이트를 승인했다. 개발·일반 검사 패키지와 업데이트 활성 개인용 배포를 구분한다. 인증서 준비·서명 검증은 범위에서 제외하고 해시·저장소·버전 확인과 실제 두 버전 업데이트 검증은 유지한다.
