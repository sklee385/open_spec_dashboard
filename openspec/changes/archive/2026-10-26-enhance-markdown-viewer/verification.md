# 구현 및 검증 기록

## 구현 범위

- `MarkdownDocument`에 GFM 표·정렬·읽기 전용 체크리스트, URL 제한, 이미지 대체 텍스트·실패 안내·no-referrer를 적용했다.
- `MermaidBlock`과 `mermaidRenderer`에 지연 로드 공유, strict·HTML 라벨 비활성화, SVG 허용 목록 정제, UTF-8 64KiB 제한, 고유 ID, 비동기 결과 보호, 블록별 오류 격리, 25~200% 확대·축소·초기화·원문 열람을 구현했다.
- WorkRoom 문서 미리보기, DetailModal이 사용하는 ReviewSource, SpecsView에 연결했다. 검토 원문 줄 위치와 초안·저장 흐름을 유지했다. 기존 WorkContent의 공통 렌더러 호출과 코드 복사도 호환한다.
- 문서 전용 CSS에 내부 스크롤과 inline-size containment를 적용했다. 시퀀스에서 스타일 제거로 연결선이 사라지는 문제를 Edge에서 발견하고 `stroke="none"` 보정과 점선 보존 회귀 테스트로 수정했다.
- 사용자 안내: `docs/markdown-viewer.md`, 예제: `docs/examples/markdown-viewer.md`. 새 제품 안내 문구는 기존 한국어·영어 사전에 추가했다.

## Edge 검증과 제한

- 사용자 설치 ChatGPT 확장에 연결된 Microsoft Edge에서 실제 공통 컴포넌트를 사용하는 임시 검증 화면을 열었다. 원래 대시보드 API는 데스크톱 인증 때문에 일반 Edge 요청에 401을 반환하므로 전체 업무 화면을 브라우저에서 검증한 것으로 간주하지 않는다.
- 밝은 화면에서 표·정렬·읽기 전용 체크 상태·이미지 실패 안내·흐름도·시퀀스의 실제 표시를 확인했다. 시퀀스 연결선 보정 전 문제를 시각 확인했고 보정 후 자동 회귀 테스트가 통과했다.
- 이후 Edge 확장 연결이 끊겼다. 재확인 시 사용 가능한 브라우저 목록이 비어 있어 다른 브라우저·MCP로 대체하지 않았다.
- **미검증:** 보정 후 시퀀스의 실제 화면 재확인, 다크 모드, 좁은 화면의 큰 표·코드(특히 SpecsView의 Radix ScrollArea), 실제 도식 확대·스크롤 조작. 배율·스크롤 컨테이너·버튼은 자동 테스트로만 검증했다.
- 임시 검증 화면 파일은 제거했다. 사용자 문서 원문을 예제로 덮어쓰거나 저장하지 않았다.
