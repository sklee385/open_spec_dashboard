# Tasks

아래 체크박스는 구현·검증 진척용이며 검토 항목의 승인 상태가 아니다. 사용자의 최신 문서 검토 완료와 명시적 구현 시작 지시에 따라 진행했다. 문서 형식 검증 통과나 목록 조회는 사용자 문서 검토 완료·구현 시작·업무 완료를 대신하지 않는다. 실행 근거와 남은 검증은 verification.md에 기록한다. 2026-10-26 최신 복구 답변으로 pull 정책이 변경되어 영향받는 작업을 다시 미완료로 열었다. 이전 완료 기록은 이전 정책의 이력이며 새 초안에 대한 검증 결과가 아니다.

사용자 지시에 따라 구현 전에 proposal.md·design.md·명세 2개·이 작업 목록의 최신본을 사용자에게 다시 검토받는다. fast-forward 전용 pull·이력 분기 거부·외부 진행 작업 안내 및 도구 안에서 개발을 완료하는 동선을 포함한다. 항목별 문답은 문서 전체 검토 완료를 대신하지 않는다. 최신 문서 전체 검토와 별도의 구현 시작 지시가 있어야 아래 작업을 실행한다.

파일·폴더 생성, 파일 삭제, 이름 변경·이동은 사용자 답변에 따라 포함한다. 관련 문서 전체를 다시 검토받고 별도 구현 시작 지시를 받기 전에는 구현하지 않는다.

- 사용자는 2026-10-26 구조화 질문에서 ‘문서 검토 완료’를 선택해 최신 fast-forward 전용 pull 계획(proposal.md·design.md·명세 2개·tasks.md)의 전체 검토를 완료했다.
  이 답변은 별도 구현 시작 지시가 아니다. 미완료 작업은 구현 시작 지시 후 실행하며 이번 턴에는 제품 코드를 수정하지 않는다.
