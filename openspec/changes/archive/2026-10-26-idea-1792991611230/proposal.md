# Proposal

## Why

현재 사용하는 앱의 버전을 일반 업무 화면에서 확인하기 어려워 문의하거나 업데이트 결과를 확인할 때 번거롭다. 웹과 데스크톱의 공통 상단에서 현재 앱 버전을 확인할 수 있게 한다.

## What Changes

- 웹·데스크톱 공통 상단에 현재 버전을 항상 표시한다. 사용자가 표시 위치 선택 질문에서 공통 상단을 선택했다.
- 화면을 전환해도 버전 표시를 유지한다.
- 버전은 루트 `package.json`의 제품 버전을 프런트엔드 빌드 시 주입해 표시한다. 배포된 화면의 버전을 식별하며, 최신 배포 버전 조회는 추가하지 않는다. 사용자가 세부 표시 방식에 대해 ‘제안대로 결정’을 선택했다.
- 상단 로고 옆에 `v0.1.2` 형식으로 표시하며, 버전 정보를 읽을 수 없으면 `버전 확인 불가`를 표시한다. 번호는 예시이며 실제 값은 빌드에서 가져온다. 사용자 답변으로 배치·형식·대체 문구를 확정했다.
- 범위 제외: 업데이트 검사·설치 동작 변경, 변경 이력, 빌드 해시, 버전 복사 기능.

## Capabilities

### New Capabilities

- `app-version-display`: 웹·데스크톱 공통 헤더의 앱 버전 표시와 정보 누락 시 동작.

### Modified Capabilities

없음.

## Impact

- `frontend/vite.config.ts`: 루트 제품 버전 주입.
- `frontend/src/components/Header.tsx`와 관련 표시 컴포넌트·타입·번역: 버전 렌더링과 좁은 화면 대응.
- 데스크톱은 같은 프런트엔드 산출물을 사용하며, 패키징 버전과 표시 버전 일치 여부를 검증한다.
- 기존 데스크톱 업데이트 창에는 이미 현재 버전 표시가 있다. 이번 변경은 공통 업무 화면의 표시를 추가한다.
- 신규 외부 의존성이나 서버 API 추가 없이 진행하는 설계 초안이다. 문서 검토와 구현 시작 지시는 별도로 필요하다.
