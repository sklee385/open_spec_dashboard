# [현재 목표] AI의 확인 질문과 사용자 답변 연결

아이디어와 요구사항에서 명확하지 않은 내용이 있으면 AI가 사용자에게 질문하고, 사용자가 UI에서 답변할 수 있게 한다. 질문·답변을 해당 작업과 연결하고, 결정된 내용을 문서와 이후 개발에 반영하는 흐름을 제공한다. AI가 불명확한 요구사항을 임의로 확정하지 않도록 한다.
