# [현재 목표] 아이디어부터 개발 완료까지 한 화면에서 진행

OpenSpec 기능을 UI에서 사용하며, 아이디어 구체화부터 문서 작성·수정, 개발 진행, 검증과 완료 처리까지 같은 작업 공간에서 이어서 수행한다. 기존 ToruAI/openspec-ui는 참고 프로젝트다. 핵심 불편은 모니터링 화면에서 작업을 끝낼 수 없어 다른 도구를 오가야 한다는 점이다. 대화·문서·진행 상황을 관련 작업에 연결해 도구 이동과 맥락 재설명을 줄인다. 현재 AI 개발 도구는 Codex를 기본으로 한다.

초기 개발 필수 요구사항: 아이디어 구체화부터 요구사항 질의응답, 문서 작성·수정, 실제 개발, 검증과 완료까지 하나의 업무 세션으로 이어서 진행해야 한다. 단계마다 별도의 AI 세션을 새로 시작하거나 사용자가 맥락을 다시 전달하지 않도록, 동일 세션에서 대화·결정 사항·관련 문서·개발 진행 맥락을 유지한다.
