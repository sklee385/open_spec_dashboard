# [후속 아이디어] AI 개발 도구 선택 (기본 Codex)

기본 AI 개발 도구는 Codex로 유지하면서 사용자가 다른 AI 개발 도구를 선택할 수 있게 한다. 사용자가 현재 목표가 아닌 다음 목표로 명시한 아이디어이며, 현재 구현 범위에는 포함하지 않는다. 지원할 도구, 선택 적용 범위, 연결 방식 및 도구 변경 시 대화·작업 맥락 유지 방식은 추후 결정한다. 기존 기록: openspec/ideas/select-ai-development-tool.md.
