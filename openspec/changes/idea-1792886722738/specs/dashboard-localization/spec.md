# Spec Delta

## Purpose

대시보드 사용자가 브라우저 선호 언어에 따라 한국어 또는 영어로 일관된 제품 화면을 이용할 수 있도록 한다. 지원 언어가 없는 경우의 영어 기본값, 제품 문구와 날짜의 번역 범위, 사용자 콘텐츠의 원문 유지 조건을 정의한다.

## ADDED Requirements

### Requirement: 브라우저 선호 언어 자동 선택

시스템은 초기 진입 시 브라우저의 선호 언어 목록을 순서대로 확인하여 처음 발견한 지원 언어를 선택해야 한다(SHALL). 한국어와 영어를 지원하며 언어 태그의 대소문자와 지역 차이를 기본 언어 `ko` 또는 `en`으로 정규화해야 한다(SHALL).

#### Scenario: 한국어 지역 태그
- **WHEN** 선호 언어 목록이 `['ko-KR', 'en-US']`이다
- **THEN** 한국어 화면이 표시된다

#### Scenario: 영어 우선순위와 대소문자
- **WHEN** 선호 언어 목록이 `['EN-gb', 'ko-KR']`이다
- **THEN** 영어 화면이 표시된다

#### Scenario: 지원하지 않는 언어 건너뛰기
- **WHEN** 선호 언어 목록이 `['ja-JP', 'ko-KR', 'en-US']`이다
- **THEN** 첫 지원 언어인 한국어 화면이 표시된다

### Requirement: 영어 기본값

시스템은 선호 언어 목록이 없거나 비어 있으면 브라우저의 단일 언어 설정을 확인해야 한다(SHALL). 선택 대상에 지원 언어가 없거나 언어 정보에 접근할 수 없으면 영어로 표시해야 한다(SHALL).

#### Scenario: 단일 언어 설정 사용
- **WHEN** 선호 언어 목록이 비어 있고 단일 언어가 `ko-KR`이다
- **THEN** 한국어 화면이 표시된다

#### Scenario: 목록에 지원 언어가 없음
- **WHEN** 선호 언어 목록이 `['ja-JP', 'fr-FR']`이다
- **THEN** 영어 화면이 표시된다

#### Scenario: 단일 언어도 지원하지 않음
- **WHEN** 선호 언어 목록이 없고 단일 언어가 `fr-FR`이다
- **THEN** 영어 화면이 표시된다

#### Scenario: 언어 정보 접근 불가
- **WHEN** 브라우저 언어 정보를 읽을 수 없다
- **THEN** 언어 감지 오류로 화면을 중단하지 않고 영어로 표시한다

### Requirement: 초기 표시와 새로고침 시 언어 적용

시스템은 초기 제품 화면부터 선택한 언어를 적용하고 HTML 문서의 `lang`을 `ko` 또는 `en`으로 설정해야 한다(SHALL). 새로고침 시 브라우저 언어를 다시 평가해야 한다(SHALL). 수동 언어 선택과 언어 설정 저장은 이번 범위에 포함하지 않는다.

#### Scenario: 한국어 초기 화면
- **WHEN** 한국어가 선택된 상태로 처음 진입한다
- **THEN** 초기 제품 화면과 로딩 안내는 한국어이며 문서의 `lang`은 `ko`이다

#### Scenario: 설정 변경 후 새로고침
- **WHEN** 한국어 화면을 이용하다 브라우저 선호 언어를 영어 우선으로 변경하고 새로고침한다
- **THEN** 영어 화면이 표시되고 문서의 `lang`은 `en`이다

### Requirement: 제품 고정 문구 번역

시스템은 헤더·모바일 메뉴, 칸반·검색·정렬, 명세 화면, 아이디어 작성·상세, 설정, 업무 공간의 제품 고정 문구를 선택한 언어로 표시해야 한다(SHALL). 버튼·탭·상태 이름·빈 화면·로딩·제품 오류 안내·입력 예시·툴팁·접근성 이름을 포함해야 한다(SHALL).

#### Scenario: 한국어 주요 화면
- **WHEN** 한국어로 칸반, 명세, 아이디어 작성·상세 및 설정 화면을 연다
- **THEN** 각 화면의 제품 고정 문구, 상태 이름, 빈 화면 및 로딩 안내가 한국어로 표시된다

#### Scenario: 영어 업무 공간
- **WHEN** 영어로 업무 공간의 대화, 문서, 검증 및 OpenSpec 결과 영역을 연다
- **THEN** 각 영역의 제품 버튼·탭·상태·연결 안내가 영어로 표시된다

#### Scenario: 모바일과 접근성 안내
- **WHEN** 한국어 또는 영어 화면에서 모바일 메뉴, 입력란과 아이콘 버튼을 이용한다
- **THEN** 메뉴 문구, 입력 예시, 툴팁과 보조 기술이 읽는 제품 이름이 선택한 언어로 제공된다

#### Scenario: 제품 오류 안내
- **WHEN** 요청 실패나 화면 오류로 제품의 기본 오류 안내와 재시도 버튼이 표시된다
- **THEN** 기본 안내와 재시도 버튼은 선택한 언어로 표시된다

### Requirement: 날짜와 상대 시간 표시

시스템은 제품 화면의 날짜·시간과 상대 시간을 선택한 언어에 맞게 표시해야 한다(SHALL). 원본 시각과 기존 시간대 처리 의미는 유지해야 한다(SHALL).

#### Scenario: 생성·수정 시각
- **WHEN** 같은 아이디어의 생성·수정 시각을 한국어 화면과 영어 화면에서 확인한다
- **THEN** 각 언어의 날짜·시간 표기로 같은 시각을 나타낸다

#### Scenario: 상대 시간
- **WHEN** 한국어 또는 영어 화면에서 최근 변경의 상대 시간을 확인한다
- **THEN** 경과 시간과 단위가 선택한 언어에 맞는 표현으로 표시된다

### Requirement: 수량과 변수 표시

시스템은 개수와 이름 등 변수를 포함한 제품 문구를 선택한 언어의 어순과 수량 표현에 맞게 표시해야 한다(SHALL). 치환한 값은 보존하고 번역 키나 미치환 변수를 사용자에게 표시해서는 안 된다(MUST).

#### Scenario: 영어 단수와 복수
- **WHEN** 영어 화면에서 개수 안내의 값이 1 또는 2이다
- **THEN** 각각 단수·복수에 맞는 문구에 정확한 개수가 표시된다

#### Scenario: 이름 변수
- **WHEN** 한국어 화면에서 영어 프로젝트 이름이 포함된 제품 안내를 표시한다
- **THEN** 안내는 한국어이고 삽입한 프로젝트 이름은 원문 그대로 표시된다

### Requirement: 번역 누락의 영어 대체

시스템은 한국어 번역이 누락되면 대응하는 영어 문구를 표시해야 한다(SHALL). 정식 제공하는 모든 제품 문구는 한국어·영어 번역을 갖추어야 하며, 영어 대체만으로 번역 완료로 취급해서는 안 된다(MUST).

#### Scenario: 한국어 번역 누락
- **WHEN** 한국어 화면에서 특정 문구의 한국어 번역이 없고 영어 번역이 있다
- **THEN** 해당 문구만 영어로 표시되고 화면은 계속 동작한다

#### Scenario: 번역 완전성 검증
- **WHEN** 번역 대상 제품 문구의 한국어·영어 제공 여부를 검증한다
- **THEN** 모든 대상 문구가 두 언어로 제공되어야 하며 한쪽이라도 누락되면 검증 실패로 식별된다

### Requirement: 콘텐츠와 실행 원문 보존

시스템은 문서 본문, 아이디어·프로젝트 이름, 사용자 입력, AI 대화·질문·답변 선택지, 서버의 자유 형식 오류와 명령 출력을 번역하거나 재작성해서는 안 된다(MUST). 이를 둘러싼 제품 고정 문구는 번역해야 한다(SHALL).

#### Scenario: 다른 언어의 콘텐츠
- **WHEN** 영어 화면에서 한국어 아이디어, 문서 또는 AI 질문과 답변 선택지를 연다
- **THEN** 해당 콘텐츠는 한국어 원문으로 유지되고 제품의 닫기·저장·답변 제출 문구는 영어로 표시된다

#### Scenario: 서버 오류와 명령 출력
- **WHEN** 영어 화면에서 서버의 한국어 오류 또는 한국어가 포함된 명령 출력을 표시한다
- **THEN** 수신한 원문은 유지되고 결과 영역의 제품 안내는 영어로 표시된다

### Requirement: 기존 업무와 데이터 호환성

시스템은 표시 언어에 관계없이 API 필드·상태 식별자·저장 데이터·문서 경로와 기존 업무 동작을 유지해야 한다(SHALL). 화면 언어 선택으로 문서 작성 언어나 AI 지시 언어를 변경해서는 안 된다(MUST).

#### Scenario: 표시 상태와 저장 상태
- **WHEN** 같은 업무를 한국어와 영어 화면에서 조회한다
- **THEN** 상태 이름은 번역되지만 업무 식별자와 API 상태 값은 같다

#### Scenario: 저장과 업무 동작
- **WHEN** 한국어 또는 영어 화면에서 기존 아이디어 저장, 문서 저장 또는 업무 동작을 수행한다
- **THEN** 기존과 동일한 데이터와 작업 의미가 유지된다

#### Scenario: 작성 언어 보존
- **WHEN** 브라우저 언어를 영어로 변경하고 기존 한국어 업무를 계속한다
- **THEN** 화면 언어 변경만으로 문서 작성 언어나 AI 지시 언어가 변경되지 않는다
