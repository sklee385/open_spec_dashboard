# Tasks

구현은 사용자가 계획 문서를 검토한 뒤 명시적으로 요청할 때 시작한다. 아래 체크박스는 구현 진행률이며 문서 작성으로 완료 처리하지 않는다.

## 1. 공통 추출과 API

- [ ] 1.1 Markdown 목록 기반 검토 항목 추출기를 구현하고 네 종류 표기·다중 줄·코드/주석 제외·일반 체크박스 제외를 단위 테스트로 검증한다.
- [ ] 1.2 변경·업무별 검토 항목 조회 API와 문서 버전·부분 실패 응답을 추가하고 다른 업무 격리·경로 이탈·누락 문서·권한 실패를 백엔드 테스트로 검증한다.
- [ ] 1.3 생성 AI 지침과 사용자 안내에 표기 규약·이전 문서 호환·항목별 승인 미지원 정책을 기록하고 예제 문서의 추출 결과를 테스트한다.

## 2. 검토 탭과 원문 이동

- [ ] 2.1 공유 검토 목록 컴포넌트를 DetailModal·WorkRoom에 연결하고 문서별 그룹·종류·로딩·빈 목록·부분 오류·재시도를 프런트엔드 테스트로 검증한다.
- [ ] 2.2 원문 위치 이동을 구현하고 미저장 편집의 저장·폐기·취소와 문서 버전 변경 후 위치 재조회를 WorkRoom 회귀 테스트로 검증한다.
- [ ] 2.3 저장 성공·SSE 갱신을 목록에 연결하고 항목 추가·수정·삭제 및 오래된 응답 무시를 테스트한다. 탭 열람 전후 reviewedVersion이 같음을 검증한다.

## 3. 통합 검증

- [ ] 3.1 npm test와 npm run build를 실행하고 Microsoft Edge의 ChatGPT 확장에서 두 화면의 검토 목록·원문 이동·오류 복구를 확인한다. 확장에 접근할 수 없으면 미검증으로 기록한다.
