# AI 작성 문서의 사용자 검토 항목을 별도 탭으로 표시

## 아이디어
AI가 spec, proposal, design 등의 문서를 작성할 때 사용자가 검토해야 할 항목을 별도의 탭에 모아 보여준다.

## 표시 위치
변경 상세 화면의 Proposal / Specs / Tasks / Design 탭 옆에 사용자 검토용 탭을 추가한다.

## 기대 효과
사용자는 문서 전체를 일일이 찾아보지 않고도 확인하거나 결정해야 할 내용을 한곳에서 검토할 수 있다.

## 검토 항목 예시
- 사용자 확인이 필요한 요구사항과 AI가 가정한 내용
- 미결정 사항과 선택이 필요한 대안
- 문서에서 명시적으로 검토를 요청한 항목

## 참고
사용자가 제공한 변경 상세 화면의 탭 구성을 기준으로 한 아이디어이며, 세부 동작은 구현 전에 정한다.
