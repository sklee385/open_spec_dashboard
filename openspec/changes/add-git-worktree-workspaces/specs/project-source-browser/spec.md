# Spec Delta

## MODIFIED Requirements

### Requirement: 원본과 연결 업무 공간 선택
시스템은 등록 프로젝트 원본, 연결된 활성 업무의 검증된 공간, 해당 업무의 소유 통합 후보를 선택해 탐색·편집할 수 있어야 한다(SHALL). 공간 전환 시 미저장 보호를 적용하고 다른 프로젝트 업무·임의 경로·변조되거나 오래된 공간/후보 식별 정보의 접근을 거부해야 한다(MUST).

#### Scenario: AI 코드 편집과 원본 반영 후 커밋
- **WHEN** 사용자가 연결 업무 공간을 선택해 AI가 수정한 코드를 직접 편집한다
- **THEN** 같은 업무 공간에서 검증하고 복사 업무는 기존 원본 반영 후 원본에서 커밋하며 워크트리 업무는 결과 커밋·후보 검증·확정으로 이어지고 원본을 자동 덮어쓰지 않는다

#### Scenario: 잘못된 업무 공간 지정
- **WHEN** 요청한 업무가 없거나 다른 프로젝트에 속하거나 공간 식별 정보가 변조되었다
- **THEN** 시스템은 해당 공간을 열거나 수정하지 않고 오류를 표시한다

#### Scenario: Git 없는 업무 복사 공간
- **WHEN** 선택한 업무 공간에 Git 저장소가 없다
- **THEN** 소스 편집·업무 검증은 유지하고 원본 반영 후 원본에서 커밋하도록 안내하며 저장소를 자동 생성하지 않는다

#### Scenario: 통합 후보 편집
- **WHEN** 사용자가 연결된 후보를 선택하고 충돌 파일을 편집한다
- **THEN** 서버는 후보 ID와 프로젝트·업무·소유 경로를 확인하고 후보 변경으로 검증을 무효화하며 원본이나 업무 브랜치를 수정하지 않는다

#### Scenario: 후보 전환 중 미저장 편집
- **WHEN** 미저장 편집을 가진 사용자가 업무 공간과 후보 사이를 이동한다
- **THEN** 저장·폐기·이동 취소를 제공하고 후보 재생성으로 이전 ID가 무효가 되면 오래된 저장을 거부하며 초안을 유지한다
