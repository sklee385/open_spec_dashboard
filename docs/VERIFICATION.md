# 구현 검증 기록

검증일: 2026-10-25. 새 화면은 13001, NestJS API는 13002이며 기존 설치본 13000은 유지한다. 기능 구현은 `unified-codex-work-session` 작업 목록에서 추적한다.

## 7.4 후속 구현 검증 (2026-10-25)

사용자가 확인 질문에서 ‘7.4 구현 시작’을 선택한 후 진행했다. 마지막 문서·대화/자료 영역·자료 탭을 변경별로 저장하고 복원하도록 보완했다. 저장된 경로가 현재 업무 문서 목록에 없으면 첫 문서로 돌아간다. SSE 연결 복구 시 이벤트 유무와 관계없이 업무 상태를 다시 조회한다.

- 변경 전 업무 화면 테스트 13개 통과. 새로고침 후 화면 선택 복원 누락과 연결 복구 후 상태 재조회 누락을 추가 테스트로 재현한 뒤 보완했다.
- `npm run test:run --workspace frontend`: 9개 파일, 74개 테스트 통과. 업무 화면의 17개 테스트에는 같은 멱등 키와 업무 ID 재사용, 마지막 문서·탭·초안 복원, 미저장 상태의 페이지 종료 경고, 재연결 시 초안 보존, 손상된 화면 정보와 허용 목록 밖 경로의 복원 방지가 포함된다.
- `npm run build --workspace frontend`: TypeScript 검사 및 Vite 빌드 통과. 약 598 kB JavaScript 묶음의 기존 크기 안내는 남는다.
- 커밋 전 다른 업무의 미커밋 다국어 변경을 제외하고 HEAD에 7.4 변경만 적용한 별도 복사본에서도 프런트엔드 5개 파일·29개 테스트, TypeScript 검사 및 Vite 빌드가 통과했다. 이 복사본의 JavaScript 묶음은 약 573 kB이며 같은 크기 안내가 남는다. 위 74개 테스트는 다른 업무 변경을 포함한 작업 폴더의 검증 결과다.
- 현재 세션에는 사용자 설치 Microsoft Edge ChatGPT 확장에 접근할 도구가 노출되어 있지 않다. 이번 변경의 실제 브라우저 및 좁은 화면 배치 검증은 미검증이다. 아래 기존 Edge 기록은 이전 검증 결과다.
- 사용법은 `USAGE.md`의 재연결과 복구 항목에 반영했다. 작업 체크 완료는 사용자 최종 검토·완료 확인·OpenSpec 보관을 대신하지 않는다.

테스트 업무 `structured-sum`의 실제 보관은 자동 승인 검토가 해당 실행의 명시적 승인 부족을 이유로 거부하여 수행하지 않았다. 완료 상태를 유지한다. 별도의 임시 통합 테스트에서는 실제 CLI 보관, 기준 명세 반영, 파일 이동, 보관 카드·원래 이름으로 업무 재열기를 검증했다. 주 변경 자체는 사용자 결과 검토·완료 확인 전 보관하지 않는다.

## Edge 화면과 충돌

Microsoft Edge의 사용자 설치 확장 연결로 검증했다. 프로젝트 선택, 업무 열기, 새로고침 후 업무 복원, 실제 질문 카드 답변, 문서 편집, 실행·검증 화면, OpenSpec 조회 및 완료 처리까지 확인했다.

별도 `add-function` 업무에서 편집 중인 초안을 만든 뒤 파일을 외부 변경했다. 저장 시 409와 최신 문서·초안 비교를 확인하고 ‘최신 버전에 내 초안 재적용’ 후 저장 상태를 확인했다. 증거 이미지는 `.data/e2e/conflict.png`다.

실제 CLI의 status, diff, validate, doctor, deltas, schemas, context 결과를 조회했다. 상태와 의존성은 화면에서 표로 표시하고 원본 결과를 펼쳐 확인할 수 있다. 문서 검증 실패는 코드 검증과 구분하며 동일 대화로 수정 요청을 준비할 수 있다.

## 자동 검증

- 프런트엔드 16개, 백엔드 48개 테스트 통과. 대화 생성 결과 유실·복원 실패·중단·프로세스 세대·질문 만료/복구·초안 보존·충돌·프로젝트 경계·SSE 커서/중복 정리·아이디어 부분 실패 재시도·필수 완료 조건을 포함한다.
- 서버 HTTP SSE의 실제 update 이벤트는 정상 전달됨을 확인했다. 열린 보드의 이벤트 누락·갱신 지연을 보완하기 위해 5초 주기 조회를 추가했다. 갱신 중 기존 카드를 유지하며 최신 진행률 34/35가 표시되는 것을 Edge에서 확인했다.
- TypeScript 검사와 React/Vite 및 NestJS 빌드 통과.
- OpenSpec `validate unified-codex-work-session --strict` 통과.
- 운영 의존성 `npm audit --omit=dev`: 취약점 0건. NestJS의 간접 의존성 Multer는 수정 버전 2.5.0으로 고정했다.
- 프로덕션 JavaScript 묶음이 500 kB를 넘는 Vite 안내가 남는다. 빌드 실패는 아니며 현재 기능 검증을 통과했다.

## 남은 수동 확인

좁은 화면의 대화·자료 탭은 구현하고 컴포넌트 전환을 테스트했다. 현재 Edge 확장은 창 크기 변경 기능을 제공하지 않아 실제 좁은 화면의 배치 검증은 하지 못했다. 데스크톱 화면 검증과 구분하여 미검증으로 남긴다.

백업·재시작·원래 설치본으로 복귀 절차는 `USAGE.md`, API와 프로토콜 계약은 `API.md`와 `CODEX.md`를 따른다.
