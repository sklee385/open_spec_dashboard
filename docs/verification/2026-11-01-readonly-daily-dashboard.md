# 읽기 전용 일일 현황판 구현·검증 결과

별도 `codex/readonly-daily-dashboard` worktree에서 v0.1.20 배포/지정 portable 업데이트 완료 뒤 후속 개발했다. **이 현황판은 미배포**다. 현재 정상 실행 앱과 13003 서버를 재시작하지 않았다.

## 구현

- 날짜/시간대 선택, 선택 날짜의 고유 업무·명시 완료와 확인 시각이 붙은 현재 상태를 분리했다. pending 생성 시각 외에 오류·실행 시작을 확실히 연결할 수 없으면 시각 확인 필요로 둔다. 마지막 활동으로 상태 발생 시점을 추정하지 않는다.
- SQL 날짜 집계, 제한된 업무 페이지, 주요 이력 cursor 페이지와 240자 미리보기를 추가했다. stream 조각·transport 통지를 제외하고 같은 turn/item 완료 재통지는 날짜를 넘어도 첫 기록으로 묶는다.
- 대화 첫 기록 시각과 seq를 보존하고 오래된 메시지/주요 기록 원문으로 이동한다. 없는 시각은 만들지 않는다. 원문 요청 뒤 다른 화면으로 이동한 경우 늦은 응답은 새 화면을 덮지 않는다.
- 새 상태 변경 API·실행/재실행·AI 요약·생산성 점수는 없다. 기존 DB 내용은 보정하지 않고 조회 인덱스만 준비한다.

## 자동 검사

backend **8개**, frontend **76개** 직접 영향 사례 통과. 각 사례의 최신 결과를 합쳤으며 같은 제목을 가진 기존 언어 매개변수 사례도 구분했다. 불변 코드의 성공 결과는 재사용하고 실패/관련 수정 사례만 다시 확인했다. 전체 suite는 실행하지 않았다.

- backend: 한국/UTC 날짜 경계·입력 제한·고유 업무와 실행 회차·AI 종료와 명시 완료 구분·stream/reconnect 중복·runtime/pending 근거·시각 불명·source 구분·이력 cursor·목록 페이지·읽기 전용 불변.
- 새 UI/helper: 날짜/시간대·이력 페이지·원문 seq·늦은 응답 배제·오류/빈 상태/실제 0·첫 timestamp와 중복/완료 병합·오래된 메시지 창·App 원문 이동과 다른 화면 보존.
- 기존 직접 영향: WorkRoom, 질문 위치·초안, polling, App 알림 이동, 헤더와 언어 사전.
- 양쪽 최종 빌드 통과. 새 화면 두 파일의 정적 화면 검사 0 FAIL / 0 WARN. 선택 runner는 새 변경 범위로 갱신하고 문법/--list만 확인했다. 같은 사례를 runner로 또 실행하지 않았다.

UI 검사 초기 실패 1개는 요약과 행의 같은 ‘확인 필요’를 단일 조회한 검사 오류였다. 제품 상태를 바꾸지 않고 조회를 수정해 통과했다. 초기 props 타입/미사용 인자 빌드 오류도 수정했다. 최신 결과에 실패가 남지 않았다.

## Codex 내장 브라우저

가짜 업무 3개·독립 DB·임의 loopback 포트·알림 비활성 설정·GET 전용 검증 서버를 사용했다. 사용자 대화/파일은 복사하지 않았다.

1. 오늘 활동 1개와 현재 대기/오류를 구분했다. 빈 과거 날짜는 활동 0이면서 현재 상태는 유지했다. 과거 날짜와 UTC 전환도 확인했다. native date fill이 반영되지 않아 기본 날짜 키보드 조작을 사용했고 다른 브라우저로 우회하지 않았다.
2. 이력 첫 30건과 추가 페이지를 합친 40건, 날짜 범위 복귀, AI 원문 이동·강조·보존된 UTC 시각을 확인했다.
3. 생성 시각이 있는 이전 pending과 오류 시작 시각 불명의 최종 표시를 확인했다.
4. 기본 desktop/768px/390px을 확인했다. 768px client/scroll width는 760/760, 390px은 382/382로 가로 넘침이 없었다. 모바일 메뉴와 행별 과거 활동/현재 상태 라벨을 확인했다. viewport를 복원하고 만든 탭·검증 서버를 정리했다.

디자인은 achromatic-ledger(seed 2144612991)를 기존 팔레트·폰트·shell에 맞췄다. 화면 질문은 ‘그날 어떤 업무를 했고, 지금 무엇이 확인을 기다리는가?’다. 사용자 정책에 따라 별도 브라우저 inspector 대신 Codex IAB 실제 화면을 대조했다.

스크린샷과 JSON은 ignored `.tools/daily-dashboard-preview-final.png`, `.tools/daily-dashboard-preview-mobile-final.png`, `.tools/daily-verification-summary.json`에 보관했다. 세 업무명과 문서 35개는 검증용 가짜 데이터다.

## 게시 상태

현황판 구현·관련 검증은 완료했다. 새 공개 릴리스/CI dispatch/설치 파일/지정 앱 재업데이트는 하지 않았다. 물리 모바일 기기나 외부 원격 연결을 새로 검증한 것도 아니다. 현재 사용 앱은 정식 v0.1.20을 유지한다.
