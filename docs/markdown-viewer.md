# Markdown 문서 뷰어

업무 공간의 문서 미리보기, 변경 상세의 제안서·설계·명세·작업 목록, 명세 조회에 같은 표시 규칙을 적용합니다. 미리보기는 Markdown 원문을 저장하거나 변환하지 않습니다. 대화 출력의 코드 복사 기능은 기존 동작을 유지합니다.

- 기본 Markdown: 제목, 문단, 인용, 순서·비순서 목록, 구분선, 강조, 인라인 코드, 코드 블록, 링크와 이미지.
- GFM: 표와 열 정렬, 읽기 전용 체크리스트, 취소선, 자동 링크.
- 다이어그램: `mermaid` 코드 블록. 흐름도와 시퀀스를 검증 대상으로 지원하며 다른 Mermaid 문법은 같은 보안·오류 규칙을 적용합니다.
- 기타 언어의 코드 블록은 원문 코드로 표시합니다. 원문 HTML은 실행·해석하지 않고 텍스트로 표시합니다. Mermaid 이외의 다이어그램 언어는 도식으로 변환하지 않습니다.

넓은 표와 코드는 내부에서 가로로 스크롤합니다. 도식은 가로·세로 스크롤, 25% 단위의 25~200% 확대·축소, 100% 초기화를 제공합니다. ‘다이어그램 원문’을 열면 원문을 확인할 수 있습니다. Mermaid 문법·라이브러리 로딩·SVG 처리 실패와 UTF-8 64KiB 초과는 해당 블록의 안내와 열린 원문으로 표시합니다.

링크는 HTTP·HTTPS·메일(`mailto:`)·문서 내 앵커(`#...`)만 허용합니다. 이미지에는 HTTP·HTTPS 및 앱 기준 상대 주소를 허용하고, `javascript:`, `file:`, `data:` 및 프로토콜 생략 외부 주소(`//...`)는 차단합니다. 상대 이미지 주소는 Markdown 파일 폴더 기준이 아니라 현재 앱 URL 기준입니다. 저장소 파일을 제공하는 새 서버는 없으므로 앱이 제공하지 않는 경로는 실패 안내로 표시됩니다. 이미지에는 대체 텍스트와 `no-referrer`를 적용합니다.

Mermaid는 strict 모드와 HTML 라벨 비활성화를 사용합니다. SVG의 스크립트·이벤트·링크·이미지·스타일 등 허용하지 않은 내용은 제거합니다. 도식의 색·서식 일부가 단순화될 수 있으며 도형·텍스트·연결선을 기본 색으로 보존합니다.
