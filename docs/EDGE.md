# OpenSpecBoard의 Edge 연결

OpenSpecBoard 전용 확장을 통해 선택한 Microsoft Edge 탭을 새 Codex 업무에 연결합니다. ChatGPT 공식 확장과 별개이며, 브라우저 MCP나 원격 디버깅 포트를 사용하지 않습니다.

## 설치와 연결

1. Edge 연동 코드가 반영된 OpenSpecBoard를 실행합니다. 기존 개발 환경은 실행·질문·승인·대기 메시지를 모두 정리한 뒤 `./scripts/restart.ps1 -Service session`으로 반영합니다. 코드 수정만으로 실행 중 세션 서버를 재시작하지 않습니다. 데스크톱 설치본은 확장이 포함된 새 빌드가 필요합니다.
2. 설정의 **Edge 연결**을 펼쳐 확장 폴더 경로를 확인합니다. 소스 실행 환경에서는 저장소의 `edge-extension`이며, 데스크톱 배포본에는 `service/edge-extension`으로 포함됩니다.
3. Edge에서 `edge://extensions`를 열고 **개발자 모드 → 압축 풀린 파일 로드**로 해당 폴더를 직접 선택합니다. 확장은 스토어에 게시하거나 자동 설치하지 않습니다.
4. **새 Codex 업무** 화면의 **Edge 연결 → 연결 코드 만들기**를 누릅니다. 로컬 연결 주소와 2분간 유효한 일회성 코드가 표시됩니다.
5. Edge에서 조작할 HTTP/HTTPS 탭을 선택합니다. OpenSpecBoard 확장을 열고 주소와 코드를 붙여넣은 뒤 **현재 탭 연결**을 누릅니다.
6. 업무 화면의 **연결 상태 확인**으로 실제 연결된 탭 제목·주소가 맞는지 확인합니다. Codex에 해당 화면을 읽거나 조작하도록 요청할 수 있습니다.

연결 코드는 재사용할 수 없으며 새로 발급하면 이전 코드가 무효가 됩니다. 브라우저 확장에는 별도의 연결 토큰을 전달하며, OpenSpecBoard 앱 인증값은 전달하지 않습니다.

## 기존 대화와 실행 범위

설치된 Codex app-server의 실험적 프로토콜은 새 대화의 `dynamicTools` 등록을 지원하지만, 기존 대화 재개 시 도구 추가 필드는 제공하지 않습니다. 따라서 이번 버전 이전에 만들어진 대화는 자동 교체하지 않고 **Edge 도구가 없는 대화**로 안내합니다. 이 버전에서 생성한 새 Codex 업무에서 연결하세요. 외부 AI CLI에는 이 기능을 제공하지 않습니다.

연결 대상은 사용자가 선택한 탭과 사이트입니다. 같은 사이트 안의 페이지 이동은 새 관찰로 반영합니다. 다른 사이트로 이동하거나 탭을 닫으면 다시 연결해야 합니다. 기존 요소 ID는 클릭·입력·스크롤 및 화면 변경 후 재사용할 수 없습니다.

지원 동작은 본문·요소 읽기, 일반 입력란 입력, 요소 클릭, 스크롤, 활성 탭 화면 캡처입니다. 비밀번호·파일 입력, 임의 JavaScript 실행, 쿠키·인증값 추출과 iframe·shadow DOM 내부 조작은 지원하지 않습니다. 캡처하려면 연결한 탭과 창이 활성 상태여야 합니다. 연결 승인만으로 구매·삭제·민감한 제출 등을 승인한 것으로 취급하지 않습니다.

## 해제와 복구

업무 화면의 **Edge 연결 해제** 또는 확장의 **연결 해제**를 사용합니다. 일정 시간 확장과 통신하지 못하거나 서버를 재시작하면 새 코드로 다시 연결하세요. 시간 초과·취소·연결 해제 후 조작을 자동 반복하지 않습니다. 이미 실행을 시작한 브라우저 입력은 되돌릴 수 없으므로 결과를 새로 관찰하고 다음 동작을 판단합니다.

여러 OpenSpecBoard 프로필 또는 웹·데스크톱 환경을 함께 사용하면 **연결할 업무 화면에 나온 주소·코드**를 사용하세요. 현재 확장 인스턴스는 하나의 업무 탭만 연결합니다.

## 사용자 직접 검증

브라우저 실제 화면 검증은 사용자가 진행합니다. 아래는 연결 후 확인할 항목입니다.

- 새 업무와 탭을 연결하면 업무 화면의 제목·주소가 선택한 탭과 일치하는지 확인합니다.
- 시험용 페이지의 일반 버튼·입력란·스크롤을 요청하고 실제 화면에서 반영을 확인합니다.
- 다른 탭을 활성화한 상태에서 캡처가 거절되는지 확인합니다.
- 같은 사이트 이동 후 새 관찰이 가능하고, 다른 사이트 이동·탭 닫기·수동 해제 뒤 조작이 중단되는지 확인합니다.
- 서비스 재시작 뒤 새 연결이 필요하며 기존 대화·다른 업무의 질문·승인이 보존되는지 확인합니다.

자동 검사 명령:

```powershell
./scripts/node.ps1 --test edge-extension/test/*.test.cjs
./scripts/npm.ps1 run test:run --workspace backend test/edge-browser.test.ts test/edge-api.test.ts test/edge-codex.test.ts test/edge-roundtrip.test.ts
./scripts/npm.ps1 run test:run --workspace frontend -- src/components/EdgeConnection.test.tsx
./scripts/npm.ps1 run build
```

자동 테스트와 빌드 통과는 실제 Edge 확장 설치·권한 승인·화면 조작 통과를 의미하지 않습니다.

## 구현 검증 기록 (2026-10-26)

- 백엔드 전체: 242개 통과, 2개 건너뜀. 전체 실행 시작 후 추가한 통합 테스트를 포함해 Edge 관련 4개 파일 12개 테스트를 최종 수정 후 별도로 통과했습니다.
- 프런트엔드 전체: 224개 통과. 데스크톱: 72개 통과. 확장: 30개 통과.
- 백엔드·프런트엔드 빌드, Windows x64 로컬 패키징 통과. 패키지의 확장 파일 6개가 소스와 해시가 일치하고 백엔드 브라우저 모듈 4개가 포함된 것을 확인했습니다.
- 코드 검토에서 발견한 재연결 중 명령 소유권 경합, 같은 사이트 새 문서의 관찰 실패, 탭 URL 접근 상실 시 해제 누락을 수정하고 회귀 테스트를 추가했습니다.
- 로컬 실행 파일: `.tools/desktop-dist-edge-integration/win-unpacked/OpenSpecBoard.exe`. 폴더 전체를 유지한 채 실행합니다. 설치본 교체·스토어 게시·서명은 수행하지 않았습니다.
- 실행 중 세션 서버 재시작, 확장 설치와 실제 Edge 화면 검증은 수행하지 않았습니다. 사용 중 업무를 정리한 뒤 새 빌드로 실행하고 위 연결 절차에 따라 사용자가 확인합니다.
