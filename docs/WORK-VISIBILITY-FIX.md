# 업무 표시 연속성 수정 (2026-10-25)

아이디어 전환 시 원본을 `source-ideas`로 보존한 다음, `tasks.md`가 없는 변경을 서버가 draft로 분류한다. 기존 보드가 draft를 일괄 제외하면서 업무가 Ideas와 작업 목록에서 동시에 빠졌다.

초안 열을 추가하고 상태 제외 조건을 제거했다. 출처 제목을 카드·검색·업무 공간에서 유지하며 원래 변경 이름과 업무 ID도 보존한다. 서버 파서는 출처 또는 일부 문서만 남은 변경도 반환한다. 의도적인 프로젝트·검색·보관 필터는 유지한다.

실행 중인 승인 요청을 유지하기 위해 처음에는 서버 재시작 없이 이전 API의 source-idea 이벤트에서 제목을 복원하는 호환 처리를 적용했다. 제목 조회가 실패해도 카드는 남긴다. 이후 PC 메모리 부족으로 서버가 종료되어 최신 빌드를 256 MB 힙 한도로 다시 실행했다. 현재 서버 파서 보완도 적용되어 있다. 다국어 업무 두 건의 ID·Codex 대화 ID·문서는 유지되며 중단된 실행은 recovery-required 상태로 복원됐다. 사용자는 같은 업무에서 대화를 이어가며 필요한 승인을 다시 확인한다.

자동 테스트는 상태별 카드 유지·같은 ID 클릭·제목 검색·모바일 초안 탭·출처만 남은 변경·일부 문서 조회·이전 서버 제목 복구 및 복구 실패 시 카드 유지까지 포함한다. Edge 사용자 확장으로 실제 다국어 초안 두 건과 기존 업무 대화 접근을 확인했다.

프런트엔드 21개와 백엔드 49개 테스트 및 양쪽 빌드의 성공을 확인했다. 마지막 전체 재실행과 단일 워커 재시도는 OS 메모리 할당 실패로 실행하지 못했으며 성공으로 간주하지 않는다. 추가 부하를 주는 재시도는 중지했다. 서버 재시작 후 API와 Edge에서 두 업무의 초안 표시·제목 검색을 재확인했다. 화면 증거는 `.data/e2e/work-visibility.png`에 저장했다.
