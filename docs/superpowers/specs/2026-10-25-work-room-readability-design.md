# 작업 대화와 실행 요청 가독성

사용자 승인: 2026-10-25, 최신 대화 자동 이동·권한 요청 요약·코드 및 JSON 구문 표시 방식 승인.

- 업무를 열거나 대화 내용이 갱신되면 대화 스크롤 컨테이너만 맨 아래로 이동한다. 주기적 상태 조회만으로는 이동하지 않는다. 모바일에서 대화 탭으로 돌아와도 최신 내용을 표시한다.
- 권한 요청은 요청 유형, 이유, 실행 명령, 작업 경로, 파일·네트워크 권한을 구분한다. 없는 정보는 추측하지 않는다. 원본 요청은 접힌 상세 정보로 보존하며 승인 API와 요청 범위는 변경하지 않는다.
- 공통 코드 컴포넌트는 언어 이름, 기본 구문 색상, 가로 스크롤, 복사 기능을 제공한다. 유효한 JSON은 들여쓰기로 정리하고 잘못된 JSON은 원문을 보존한다. React 텍스트 노드로 표시해 실행 가능한 HTML을 삽입하지 않는다.
- 대화·문서 미리보기·변경 파일·이벤트 JSON에서 공통 표시를 사용한다. 일반 문장은 기존 Markdown으로 표시한다. 편집 및 문서 초안 복원은 유지한다.
- 기존 한국어·영어 UI를 모두 지원한다. 회귀 테스트, 전체 프런트엔드 테스트, 빌드로 검증한다. 브라우저 검증은 사용자 지정 Edge ChatGPT 확장 접근이 가능한 경우에만 수행한다.
