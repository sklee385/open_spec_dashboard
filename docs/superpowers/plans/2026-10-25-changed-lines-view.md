# 수정된 줄 중심의 코드 검토

요구사항: 전체 변경 전·후 코드를 각각 읽지 않고 수정된 위치와 내용을 빠르게 확인한다.

구현: 기존 diff 9.0.0 의존성을 프런트엔드 직접 의존성으로 등록한다. 파일을 열 때만 줄 단위 차이를 계산하며 앞뒤 3줄 외의 동일 구간을 접는다. 추가·삭제를 색상과 기호로 구분하고 양쪽 줄 번호 및 변경 줄 수를 표시한다. 기존 전체 코드 보기는 접힌 별도 영역으로 유지한다. 한국어·영어를 지원한다.

경계: 새 파일·삭제 파일·빈 파일·마지막 개행 유무를 처리한다. 텍스트가 저장되지 않은 파일은 명확히 안내한다. 계산 시간과 편집 거리 한도를 두고 제한에 걸리면 전체 코드 보기로 안내한다. 원본 코드는 React 텍스트로 렌더링한다.

검증: 수정 줄·줄 번호·동일 구간 펼치기·추가/삭제 파일·비교 불가·마지막 개행 테스트를 수행한다. Edge 확장에서 실제 업무의 변경 파일 화면을 확인한다. 다른 업무가 작성 중인 파일과 테스트는 덮어쓰지 않는다.

결과: 새 비교 테스트 4개 통과 및 Vite 번들 빌드 통과. Edge에서 기존 client.ts의 4줄 추가·2줄 삭제, 변경 전·후 줄 번호와 문맥 접기를 확인했다. 전체 타입 검사에는 다른 변경에서 작성 중인 ApprovalRequest 타입 및 미완성 MarkdownDocument/MermaidBlock 테스트 오류 등이 남아 있다. 기존 WorkRoom 테스트 중 승인 버튼 문구 불일치 1건은 실패하며 나머지 19건 및 새 비교 4건은 통과했다.
