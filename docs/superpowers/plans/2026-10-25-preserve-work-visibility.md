# 업무 표시 연속성 수정 계획

사용자가 승인한 원칙: 업무는 단계가 바뀌었다는 이유로 중간에 목록에서 사라지지 않는다.

1. 회귀 테스트로 아이디어 → 문서 없는 초안 → 문서 작성 → 구현 → 완료 → 보관 상태의 카드 접근을 확인한다. 제목 검색과 카드 클릭은 기존 업무 ID를 유지한다. 사용자가 선택한 프로젝트·검색·보관 필터는 유지한다.
2. 보드에 초안 열을 추가하고 draft 제외 조건을 제거한다. 서버는 보존된 출처 아이디어의 제목을 반환하고, 카드·업무 화면·검색에서 사용한다. 식별자와 OpenSpec 변경명은 바꾸지 않는다. 일부 문서나 출처만 있는 변경도 파싱한다.
3. 테스트와 빌드 후 실제 실행 서버에 반영한다. Edge 확장에서 기존 다국어 업무 두 건의 표시와 접근을 확인한다. 기존 파일을 새 업무로 복제하거나 이미 작성한 문서를 변경하지 않는다.
