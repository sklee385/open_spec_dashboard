# 사용자 검토 탭

변경 상세와 업무 공간의 **사용자 검토** 탭에서 문서별 확인 항목을 보고 원문으로 이동합니다. 업무 공간에서는 기존 문서 편집과 대화로 결정을 반영하세요. 미저장 편집이 있으면 저장·폐기·취소를 선택할 수 있습니다.

업무 화면 상단의 **변경 문서 보기**를 누르면 변경 상세의 문서 탭과 검토 목록을 열 수 있습니다. 닫으면 편집 중이던 업무 화면으로 돌아옵니다.

AI와 수동 문서에 같은 규약을 적용합니다. 일반 목록의 시작에 아래 네 표기 중 하나를 사용하세요. 이어지는 설명은 해당 목록의 하위 블록으로 들여씁니다.

- [review:confirm] 비회원도 조회할 수 있는지 확인
  담당자에게 공개 범위를 확인합니다.
- [review:assumption] 사용자는 기존 계정을 보유한다고 가정
- [review:decision] 보존 기간 결정 필요
- [review:choice] 알림 방식 선택
  - 이메일
  - 앱 내 알림

코드 안의 표기는 예제로 취급합니다.

```markdown
- [review:confirm] 이 예제는 목록에 표시되지 않습니다.
```

표기 없는 이전 문서, 일반 작업 체크박스와 일반 문장에서는 항목을 추측하지 않습니다. 빈 목록은 확인할 사항이 전혀 없다는 보증이 아니므로 문서도 함께 읽어 주세요. 읽기 실패는 빈 목록과 구분하여 표시하며 재시도할 수 있습니다.

항목별 승인 상태는 저장하지 않습니다. 탭 조회나 원문 이동으로 검토 완료 또는 구현 시작이 처리되지 않습니다. 문서 수정 후 기존 **최신 문서 검토 완료** 및 **구현 시작** 절차를 사용하세요.
